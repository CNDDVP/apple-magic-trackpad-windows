# 控制中心设置状态修复

本次更新针对控制中心，保持 schema 1、v1.1.1 增强后台和驱动接口兼容。修复进入主分支，原 v1.2.0 发行附件保留。

## 行为变化

- 指针曲线预设根据实际草稿识别和高亮，支持自定义与恢复预设值。
- 指针预设只改变 MinGain、MaxGain、MidSpeed 和 CurvePower，保留深按、开关、拖拽和高级字段。
- “仅深按预览”作为独立模式操作，模式与曲线各自显示。
- 加速介入速度显示两位小数，输入提交和字段校验避免显示值与保存值不一致。
- 原生参数按值判断修改；只保存原生项不会改写增强 JSON。
- 重新读取先保护草稿；读取内容和指纹来自同一字节快照。
- 写入与恢复结果按阶段记录，提交后异常不会误报“原配置未替换”。
- 后台确认统一核对进程、输入注册、15 秒内的内容/文件时间、进程启动时间与生效参数。

## 验证范围

核心测试 22 项；交互式界面测试 26 项，覆盖五页以及 96 / 120 / 144 DPI 显示器。故障注入使用隔离文件和内存原生参数，覆盖 API 写入、回读、注册表同步、JSON 提交前后以及恢复失败。

本机正式部署另外核对配置与图标哈希、后台进程，并通过稳定时间的 1 ms 往返确认热加载，再恢复原始 JSON 字节。对应当前程序的验收元数据见根目录 `ControlCenter_Acceptance.json`。
