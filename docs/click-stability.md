# 物理点击稳定性：按住时默认不加速

## 触发场景与调整

在 Windows 11 蓝牙连接 Apple USB-C 妙控板的实际使用中，用户反馈：单指按出震动时光标轻微上下移动，部分单击失效。只把 `AccelerateWhilePressed` 从 `true` 改为 `false` 后，用户确认「点击稳定了，按住拖动也正常」。

这是一次只改变单个开关的使用验证，说明按压期间的曲线加速是这台电脑上相关的放大因素；不据此声称解决所有设备的抖动或硬件故障。

主分支的配置模板、首次创建选项、无配置文件启动以及 JSON 缺少该字段时，均默认关闭按住期间的 S 型曲线加速。显示器补偿仍按原开关工作，普通移动和快甩跨屏的曲线也保持原样。

## 已安装用户如何使用

在控制中心「指针手感」页取消勾选「按住拖拽时也加速」，再保存并确认后台生效。单指按住拖拽仍可用；拖动期间不再叠加 S 型曲线增益。深按阈值、稳定时间、额外加力及拖拽保护不变。

安装和升级会保留已有个人 JSON。配置中明确写出的 `true` 仍然有效，程序不会强制关闭用户主动选择的按住加速。指针曲线预设保留开关状态，切换经典或轻压跨屏不会重新开启它。需要恢复旧手感时，重新勾选此项并保存即可。
