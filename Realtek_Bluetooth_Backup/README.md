# 本机蓝牙适配器驱动备份

适用范围：本机 Realtek RTL8851BU，硬件 ID `USB\VID_0BDA&PID_B851&MI_00`。
版本：1.10.1061.3000；原系统槽位 oem91.inf。目录来自当前正常工作的驱动备份。

Apple 妙控板驱动和电脑自身的蓝牙适配器驱动是两个组件。
主安装脚本不会自动安装此包。换电脑请先核对设备管理器中的硬件 ID，并优先使用该电脑或适配器厂商提供的驱动。
仅确认硬件匹配且确实需要恢复时，才以管理员运行 `pnputil /add-driver "RTL8851BU_1.10.1061.3000\Rtkfilter.inf" /install`；该命令可能要求重启。
蓝牙首次配对仍需在 Windows 设置里手动完成。
